# 🧮 Calculator Project

A simple, clean, and user-friendly **Calculator Web Application** built using **HTML, CSS, and JavaScript**. This project is designed to perform basic arithmetic operations through an easy-to-use interactive interface.

🔗 **Live Demo:**
https://omkarbondade-hub.github.io/calculator-project/

---

## 📌 About the Project

The Calculator Project is a beginner-friendly web development project that demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive application.

The calculator provides a simple interface where users can enter numbers and perform common mathematical calculations such as:

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`
* Decimal calculations `.`
* Clear `C`
* Backspace `←`
* Result `=`

The project focuses on creating a straightforward calculator that is easy to understand and use.

---

## ✨ Features

### 🔢 Basic Arithmetic Operations

The calculator supports the following operations:

| Operation      | Symbol |
| -------------- | ------ |
| Addition       | `+`    |
| Subtraction    | `-`    |
| Multiplication | `*`    |
| Division       | `/`    |
| Decimal        | `.`    |

### 🧹 Clear Button

The **C** button clears the current calculation and allows the user to start a new calculation.

### ⬅️ Backspace

The **←** button removes the last entered character, making it easy to correct mistakes.

### 🟰 Equal Button

The **=** button evaluates the entered mathematical expression and displays the result.

### 📱 Simple User Interface

The calculator has a minimal interface with clearly arranged buttons, making it easy for users to enter numbers and operators.

## ⚙️ How It Works

The calculator works through interaction between **HTML, CSS, and JavaScript**.

1. The user clicks a number button.
2. The selected number appears on the calculator display.
3. The user selects an arithmetic operator.
4. Another number can be entered.
5. The user presses the `=` button.
6. JavaScript processes the mathematical expression.
7. The calculated result is displayed on the screen.

The **C** button can be used to clear the calculation, while the **←** button can be used to remove the last character.
